# qsoku 設計文書

qsokuの設計判断と、その理由の記録。日本語のみ（英語版は作らない）。

## 位置づけ

- ここにあるのは「**なぜこうなっているか**」の記録。**現在の仕様（何をするか）は`docs/reference/`が正**であり、食い違う場合はreferenceに従う
- 設計判断を変えるときは、まず`docs/reference/`を更新する。ここは経緯として残し、判断が大きく変わった場合だけ該当箇所に追記する（書き換えて過去の理由を消さない）
- 進捗・現在地・保留事項はここには置かない。mtqgのtodo・memoにある（`CLAUDE.md`「記録の使い分け」）

## ファイル

| ファイル | 中身 |
|---|---|
| `note.md` | 最初の設計メモ（2026-09-22、原文のまま）。qsokuとは何か、名前の由来、`qsokufile`の書式、実行方式（`sh`固定・居場所の持ち帰り）、`//`の置き換え規則、管理用コマンド、実装方針、GitHubの看板の下書き |
| `history.md` | 決めたことの時系列 |
